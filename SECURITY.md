# Security Policy

## Supported Scope

Security issues are in scope for:
- `security/`
- `api/`
- `cicd/`
- `tools/opsmemory/`
- CI/security workflows in `.github/workflows/`

## Reporting a Vulnerability

Please do not disclose sensitive vulnerabilities in public issues.

Report security issues privately through GitHub Security Advisories (preferred). Include:
- affected file/path
- impact and exploitation conditions
- reproduction steps
- suggested fix (if available)

## Response Targets

- Initial acknowledgment: within 72 hours
- Triage decision: within 7 days
- Fix timeline: based on severity and blast radius

## Disclosure

After a fix is available, maintainers will coordinate responsible disclosure and update release notes in `CHANGELOG.md`.

## Additional Guidance

For defense-first boundaries and legal-use constraints, see `CYBERSEC_GUARDRAILS.md`.
